# Nikhil Verma — Personal Portfolio

> **Personal portfolio website designed with an editorial aesthetic, interactive WebGL Koi pond, draggable retro pixel art stickers, and engineering project showcases.**

---

## ✦ Overview

This portfolio combines creative design with high-performance front-end architecture. Built using **Vanilla JavaScript (ES Modules)** and **Tailwind CSS**, it features:
- **Interactive WebGL Koi Pond**: Real-time water ripples, caustics, and reactive koi swimming physics.
- **Minimalist Navigation**: Clean `Index`, `Project`, and `Contact` views with custom squiggly active indicators.
- **Featured Projects**: Curated technical deep-dives into distributed systems, machine learning pipelines, and full-stack applications.
- **Draggable Retro Pixel Stickers**: Interactive physics engine supporting smooth desktop mouse and mobile touch drag-and-drop interactions.
- **Live IST Clock**: Real-time Indian Standard Time display on the collaboration page.

##  Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone git@github.com:nikvermaaa/portfolio-website.git
   cd portfolio-website
   ```

2. **Run with any static HTTP server**:
   - Using Python:
     ```bash
     python3 -m http.server 8000
     ```
   - Using Node (`serve` or `http-server`):
     ```bash
     npx serve .
     ```
